# Security Policy

## Supported version

Security fixes are applied to the current release line.

## Reporting a vulnerability

Please do **not** open a public issue for a suspected security vulnerability.

Use GitHub's private vulnerability reporting/security-advisory flow when it is available. If it is unavailable, contact the Voidsmith Industries maintainer through the organization contact address shown on the Voidsmith Industries GitHub profile.

Never include Torn API keys, authentication cookies, session tokens, personal data, or other secrets in issues, screenshots, logs, or pull requests.

## Scope

Reports are useful when they concern userscript data handling, Torn API requests, native action preparation, update integrity, dependencies, build tooling, or repository automation. Torn.com itself is outside this repository's control.
